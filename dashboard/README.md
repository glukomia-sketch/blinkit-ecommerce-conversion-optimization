# Executive Dashboard

Open `index.html` in a browser to view the portfolio dashboard.

## What it shows
- Executive KPIs: users, sessions, purchase conversion, purchase value
- Full user-level funnel: App Open → Search → Product View → Add to Cart → Checkout → Payment → Purchase
- Discovery and checkout opportunity areas
- Conversion by user type and device
- RICE prioritization
- A/B testing roadmap

## Important
This dashboard uses the project's synthetic portfolio dataset and portfolio RICE assumptions. It does not represent proprietary Blinkit internal data.
